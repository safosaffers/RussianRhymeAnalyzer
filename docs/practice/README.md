## Что требует твоего участия (нельзя автоматизировать)
- **Регистрация на eLibrary.ru** (личный профиль) — Задание 1.
- **Проверка `[проверить]`-источников** в `01_sources.md` по arXiv/DOI перед
  включением в итоговый список (несколько ссылок не подтверждены чтением).
- **Расширение списка до 70–100** отечественными работами с eLibrary (раздел
  стиховедения/NLP) — текущий core ~40 источников.
- **Утверждение темы, цели/задач, ТЗ** с научным руководителем.
- **Лицензионная проверка** данных перед использованием (см. `03_data.md §3`).
