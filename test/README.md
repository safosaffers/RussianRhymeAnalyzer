# Тестовые прогоны (артефакты для презентации)

Сгенерировано `test/runner.py` — **без сети и API-ключа** (детекторы рифм +
генератор-заглушка из корпуса). Перегенерировать:

```bash
./venv/bin/python test/runner.py
```

## Кейсы оценки рифм

| папка | стих | что показывает |
|---|---|---|
| `pushkin/` | Пушкин, «Буря мглою…» | эталон ABAB, рифма 100% (RPST) |
| `lermontov/` | Лермонтов, «Белеет парус…» | ещё один ABAB |
| `tyutchev/` | Тютчев, «Люблю грозу…» | ещё один ABAB |
| `noise/` | строки из разных стихов | контроль: рифмы нет (RPST 0%) |

В каждой папке:
- `input.txt` — входной текст;
- `metrics.txt` — числа обоих детекторов (% слогов, схема, score, группы);
- `coloring.png` — раскраска рифм **детектором Юкавы** (послогово);
- `coloring_rpst.png` — раскраска **RPST** (по клаузулам, с ударениями).

## Кейс генерации

`gen_zima/` — best-of-N (N=6) генератором-заглушкой, тема «зима»:
- `gen_output.txt` — кандидаты, ранжированные по % зарифмованных слогов;
- `best.txt` — победитель;
- `coloring.png` — раскраска лучшего.

## Что видно (для слайдов)

- **RPST** надёжен: на `pushkin` верно красит `кро́ет/заво́ет` и `крутя́/дитя́`
  (ABAB, 100%, score 0.95), на `noise` — честные 0%.
- **Юкава** (авторский, новизна) на коротких стихах **шумит**: подсвечивает
  созвучные слоги внутри строк, а не только концевые рифмы. Это и есть
  ограничение для соответствующего слайда.
- **best-of-N** работает: лучший кандидат-заглушка поднимается наверх по метрике.

Для ИИ-генерации (Gemini/Claude/DeepSeek) запусти GUI со своим ключом —
см. `docs/LLM_SETUP.md`; live-вызов модели тут не делался (нужна сеть и ключ).
